## Issues found (this pass)

### P1 — Regression: Super Admin still saw 4 live widgets
**Cause:** Overlay order reintroduced “all access modes” widget block without `isSuperAdmin` guard.  
**Fix in .24:** Widgets only render when not Super Admin.

### P1 — Product rename incomplete
**Files:** `assets/a11y-*.js/css` still said “Fusion Resource Centre”.  
**Fix in .24:** → “Resource Centre”.

### P1 — Security: default auth hashes in repo
**Files:** `data/auth_config.php`, `data/config/auth_config.php` committed.  
**Risk:** Public repo exposes bcrypt for default keys (blsbls / lifeisgood / alliswell).  
**Fix in .24:** `.gitignore` entries. **Human must:** rotate live hashes, stop deploying committed defaults, use per-tenant `tenants/{id}/data/auth_config.php` only.

### P2 — `sql/runner_tracking.sql` in web tree
**Risk:** Schema downloadable if server allows.  
**Fix in .24:** `.htaccess` deny + `web.config` hiddenSegments when possible. Confirm `GET /sql/` → 403/404 on each host.

### P2 — Blood report “Access denied” after login
**Cause class:** Session cookie not shared with `blood_report.php` (path/name/host) **or** bootstrap not loading `AppAuth` before gate.  
**Fix in .24:** Always load `app/bootstrap.php` after tenant bootstrap.  
**Ops:** Same host, HTTPS, hard refresh after login; do not open blood report in a different subdomain without shared session.

### P2 — Windows PWA install weaker than Linux
**Cause:** `beforeinstallprompt` engagement timing + possible prior dismiss in localStorage.  
**Mitigation present:** wait 4.5s for native event; dismiss key v3; How to install fallback.  
**Ops:** HTTPS, stay on dashboard, Edge/Chrome install icon; clear site data if bar stuck.

### P3 — Advert disabled on one tenant still visible elsewhere
**Expected:** Per-tenant `DATA_PATH/config/modules.json`. Disabling on arthsathi does **not** hide on fusion/simco.  
**Ops:** On each host where ad must hide, Super Admin → Module matrix → uncheck subscription_ad → Save.

### P3 — Overlay deploy model
Partial ZIPs can regress fixed files. Prefer full tree deploy or rsync with version check (`APP_VERSION` in footer).
