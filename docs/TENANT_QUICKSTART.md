# Tenant quick start

1. **Sign in** with your organisation access key.
2. **Organisation** — set legal name, website, primary logo (PNG or SVG), favicon.
3. **Team** — add people; print directory from the team tools when needed.
4. **Email signature** — open a person’s signature link → **Copy active signature** → paste into Gmail / Outlook / Apple Mail (guide is on that page).
5. **Theme** — bottom of the left menu: Light, Dark, Reserve, or System.
6. **Sign out** — red **Sign out** button under the theme control (also **Out** on mobile header).

Privacy: use the Governance / Privacy links in the footer for data access or erasure requests.
